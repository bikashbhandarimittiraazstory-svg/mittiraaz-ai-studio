MittiRaaz AI Studio - Android Starter

यह एक शुरुआती PWA फ्रंट-एंड प्रोटोटाइप है।
अभी AI script, video generation, thumbnail generation, YouTube upload और analytics जुड़े हुए नहीं हैं।
यह कोई पूर्ण AI ऐप नहीं है और कोई paid API या billing चालू नहीं करता।

GitHub Pages पर प्रकाशित करने के लिए:
1. ZIP को extract करें।
2. अंदर की सभी फाइलें (index.html, manifest.webmanifest, sw.js, README-HI.txt) repository के main branch में upload करें।
3. Repository Settings > Pages खोलें।
4. Build and deployment में Deploy from a branch चुनें।
5. Branch: main और folder: /(root) चुनकर Save करें।
6. प्रकाशित HTTPS लिंक Chrome में खोलें और browser menu से Add to Home screen चुनें।

ध्यान दें: इस prototype को वास्तविक AI और YouTube सुविधाओं के लिए अलग backend तथा अनुमत integrations की जरूरत होगी।
